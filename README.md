# kmer_count
## Detection and analysis of multimeric plasmid assembly in public databases

find_assembly_techno.py - Identifies the sequencing/assembly technology used for plasmid assembly\
Usage: python find_assembly_techno.py <ins>input genbank file</ins> > <ins>output file</ins>

plasmid_kmer_median.pl - Calculates median of 12-nt kmer counts in plasmids\
Usage: perl plasmid_kmer_median.pl <ins>fasta file</ins> > <ins>output file</ins>
