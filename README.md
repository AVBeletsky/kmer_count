# kmer_count
# Detection and analysis of multimeric plasmid assembly in public databases

find_assembly_techno.py - Identifies the sequencing/assembly technology used for plasmid assembly\n
Usage: python find_assembly_techno.py <input_genbank_file> <output_file>

plasmid_kmer_median.pl - Calculates k-mer median of plasmids\n
Usage: perl plasmid_kmer_median.pl <fasta_file> <output_file>
